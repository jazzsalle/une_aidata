# ADR-001 고정 단일화면 레이아웃

## 상태
대체됨(Superseded). ADR-007 다중 페이지 접근성 내비게이션이 본 결정을 대체한다.

## 기존 결정
상단, 좌측, 중앙 지도, 우측, 하단 분석 Dock을 하나의 화면에 배치한다.

## 대체 이유
지도 판단, 위성·피해 근거 검토, 보고서 작성은 목적과 조작 방식이 달라 단일 화면에 모두 배치할 경우 인지부하, 키보드 이동량, 확대·재배치 복잡도가 증가한다. 메인 상황판의 좌·중·우 구조는 유지하되 피해·변화 근거와 보고서 작성은 고유 URL을 갖는 별도 페이지로 분리한다.

## 대체 결정
`decisions/ADR-007-multi-page-accessible-navigation.md`를 따른다.
