# SCN-FLOOD-IMG-001 PRE/EVENT/POST 256 타일

1. `/evidence`에 PRE·EVENT·POST 3개 단계가 표시된다.
2. 각 단계에 위성영상과 수계마스크가 각각 256×256로 표시된다.
3. 지도에는 위성영상 타일이 오버레이되지 않는다.
4. PRE -12일, EVENT 시작~종료+2일, POST 종료+12일 기준이 표와 텍스트로 제공된다.
5. EVENT 자료는 생성 Seed, 전체 표본은 대상지역 외·공식자료 아님으로 표시된다.
6. 6개 타일 세트를 보고서 근거에 반영할 수 있으나 현재 피해현황·피해예측으로 자동 기입하지 않는다.
