# 범위와 결정사항

## 포함

- 사용자 상황 입력
- 기상특보·강우·수위·유량 공공 API
- 실시간/시나리오 모드
- VWorld 지도와 위험지구·하천·관측소·피해위치·대피소
- Event 유사사례
- 위성영상·침수흔적 시계열 변화
- 풍수해 대응절차
- 판단근거·데이터 기여/부족
- 상황보고서 초안
- 상황뷰 저장

## 제외

- CCTV
- 지자체 시스템 Context 수신
- 피해예측
- NDMS 자동제출
- 자동 대피·통제·발령

## 교체 예정 Provider

- Seed DamageRecovery → T3Q NDMS Provider
- Seed Satellite → ThreeDLabs Provider
- 부산 북구청 잠정 절차 → 의왕·구미·남원 정식 매뉴얼
- Local GeoJSON → 검증된 VWorld/원천 GIS
