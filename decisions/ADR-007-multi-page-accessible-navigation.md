# ADR-007 다중 페이지 정보구조와 접근 가능한 전역 내비게이션

## 결정
주요 업무를 한 화면의 대형 탭으로 숨기지 않고 서로 다른 URL을 갖는 3개 상위 페이지로 분리한다.

- `/` 재난 상황판
- `/evidence` 피해·변화 근거
- `/report` 상황보고서 초안

상위 페이지 이동은 `nav` 안의 링크로 제공하고 현재 페이지에는 `aria-current="page"`를 적용한다. ARIA Tab 패턴은 동일 문맥의 작은 패널 전환에만 사용한다.

## 이유
- 각 업무는 목적·정보량·조작 방식이 달라 한 화면에서 동시에 제공하면 인지부하와 키보드 이동량이 증가한다.
- 고유 URL은 북마크, 브라우저 뒤로가기, 새 창 열기, 교육자료 링크와 오류 재현에 유리하다.
- WAI-ARIA Tabs는 한 번에 하나의 연관 패널을 표시하는 복합 위젯이므로 사이트 전역의 서로 다른 업무를 구분하는 주 내비게이션으로 사용하지 않는다.
- 화면낭독기 사용자는 landmark와 제목으로 페이지 구조를 빠르게 파악할 수 있다.

## 접근성 규칙
- 모든 페이지에 하나의 `h1`, 의미 있는 `document.title`, `main` landmark를 제공한다.
- 라우트 변경 후 `h1`으로 초점을 이동한다.
- 본문 바로가기 링크를 제공한다.
- 지도에서 전달되는 핵심 정보는 텍스트 목록과 표로 동등하게 제공한다.
- 위성영상 스와이프는 좌우 비교와 숫자·버튼 조작을 대체수단으로 제공한다.
- 보고서 편집은 명시적 label, 상태메시지, 로컬 저장과 다운로드 기능을 제공한다.
