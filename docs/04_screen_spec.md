## SCR-DASH-001 재난 상황판 `/`
### 목적
현재 조건을 입력·조회하고 위험지구, 유사사례, 대응절차를 지도 기반으로 판단한다.
### 배치
- 좌측: 재난상황 입력 / AI Agent
- 중앙: VWorld 지도, 하천·위험지구·행정경계·침수흔적 레이어
- 우측: 현재 판단 / 유사사례 / 대응절차 / 계획·근거
- 하단: 현재 상황 타임라인
### 완료 행동
- 현재 조건 적용·재산정
- 우선 확인지역 지도 강조
- 유사사례 선택
- Agent 질의
- 상황뷰 저장

## SCR-EVD-001 피해·변화 근거 `/evidence`
### 목적
위성영상, 침수흔적도, 피해·대응·복구 이력을 한 페이지에서 심층 검토한다.
### 구역
1. 위성영상 좌우·스와이프 비교
2. 선택 영상 메타데이터 표
3. 침수흔적도 연계 요약
4. NDMS 교체 대비 피해·대응·복구 Seed 카드
### 접근성
- 이미지 대체텍스트
- 좌우 비교 대체수단
- range label과 빠른 위치 버튼
- 표 caption, th scope
- Seed·비공식 상태 텍스트 표시

## SCR-RPT-001 상황보고서 초안 `/report`
### 목적
현재 상황과 근거를 담당자가 수정 가능한 보고서 초안으로 정리한다.
### 배치
- 좌측: 보고서 목차·검토 주의사항
- 중앙: 상황 개요·현재 조건·조치결과·피해현황 편집 폼
- 우측: Markdown 미리보기
### 완료 행동
- 브라우저 로컬 저장
- Markdown 다운로드
- NDMS 자동제출 없음
