# 서비스 개요

## 서비스 정의

사용자가 입력하거나 공개 공공 API에서 조회한 최소 현재상황을 계획·위험·과거 사건·피해복구 참고·위성/침수·매뉴얼 데이터와 연결하는 지도 기반 AI 판단지원 POC이다.

## 업무 흐름

1. 현재상황 등록
2. 특보·강우·수위·유량 조회 및 병합
3. 위험기준·위험지구·하천 조회
4. 우선 확인지역 상대순위
5. 실제/Seed 유사 Event 검색
6. 위성영상·침수흔적 변화 비교
7. 매뉴얼 기반 대응절차
8. 근거 추적
9. 검토용 상황보고서 초안

## 핵심 사용자

- 지자체 재난안전 담당자
- 읍면동·현장 담당자
- 내부 검토자
- 공개범위가 제한된 민간 사용자
