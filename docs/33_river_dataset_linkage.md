# 요약

문의하신 내용 중 **전제 하나를 정정드립니다.**

국가기본도 3종 가운데 **하천중심선(`TN_RIVER_CTLN`)에는 하천코드·하천명·하천등급이 들어 있습니다.**
필드가 없는 것은 하천경계(`TN_RIVER_BNDRY`)와 실폭(`TN_RIVER_BT`) 둘입니다.

그리고 **중심선의 하천코드는 하천일람·하천망도와 같은 7자리 체계**입니다. 전수 대조 결과
중심선 하천코드 3,314개 중 3,285개(99.1%)가 하천망도 `RIVCD_2`와 일치했고, 그중 98.8%는
하천명까지 같았습니다.

따라서 **국가기본도와 하천일람의 연결은 중심선을 경유하면 성립합니다.** 경계·실폭에도 중심선을
공간조인해 코드·이름·등급을 붙일 수 있으며, 저희가 전국으로 수행해 하천경계는 등급미확인이
1.9%까지 내려갔습니다.

말씀하신 대로 하천망도를 쓰는 것도 맞습니다. 다만 **국가기본도를 대체하는 것이 아니라 역할을
나누는 쪽**을 권합니다. 하천망도에는 소하천이 없고(전국 22,465개소), 하천망도로 경계·실폭에
등급을 조인하면 정확도가 68~78%로 떨어지면서 소하천을 국가·지방하천으로 올리는 오판이 납니다.

# 1. 국가기본도 3종의 실제 필드

원본 SHP의 DBF 헤더를 직접 읽은 결과입니다.

| 자료 | 필드 |
|---|---|
| `TN_RIVER_CTLN` 중심선 | `NF_ID` · **`RIVER_NO`(하천코드)** · **`RIVER_NM`(하천명)** · **`RIVER_SE`(등급)** · `OBCHG_DT` · `MESRMTH_SE` · `RSREG_DT` · `MNENT_NM` · `DBREG_DT` |
| `TN_RIVER_BNDRY` 하천경계 | `NF_ID` · `OBCHG_DT` · `MESRMTH_SE` · `RSREG_DT` · `MNENT_NM` · `DBREG_DT` |
| `TN_RIVER_BT` 실폭 | 위와 동일 |

중심선 3,224,769건을 등급별로 세면 이렇습니다.

| 등급 | 건수 | 하천명 보유 | 하천코드 보유 |
|---|---:|---:|---:|
| RVC001 국가하천 | 14,653 | 100% | 100% |
| RVC002 지방하천 | 164,621 | 100% | 100% |
| RVC003 소하천 | 314,942 | 10.6% | — |
| RVC004 기타하천 | 4,303 | 0.1% | — |
| RVC005 세류 | 2,726,250 | 0.1% | — |

**하천코드는 국가·지방하천 구간에만 붙어 있습니다**(보유 179,327건 = 국가 14,653 + 지방 164,621).
소하천 이하는 코드가 없고 이름도 대부분 비어 있습니다.

# 2. 중심선 하천코드와 하천망도 코드는 같은 체계입니다

두 자료의 코드를 전수 대조했습니다.

```
중심선 하천코드(RIVER_NO)      3,314개
하천망도 하천코드(RIVCD_2)     3,856개
  교집합                       3,285개
    → 중심선 기준   99.1%
    → 하천망도 기준 85.2%
  교집합 중 하천명까지 일치     3,246개 (98.8%)
```

중심선 코드의 99.1%가 하천망도에 존재하므로, **하천일람 → 하천망도 → 중심선 → (공간조인) →
경계·실폭** 경로로 국가기본도 형상까지 이름과 제원을 붙일 수 있습니다.

## 알려진 한계

하천망도 코드 3,856개 중 **571개(지방하천 553 · 국가하천 18)는 중심선 코드에 없습니다.**
그중 418개(73%)는 하천명으로는 중심선에 존재하므로 해당 구간의 코드 칸이 비어 있는 경우이고,
나머지 153개는 이름으로도 중심선에 없습니다(임진강 등 — 접경·미도시 구간으로 보입니다).

**중심선 경유 연결은 하천망도 기준 85%를 덮습니다.** 나머지는 하천명 대조나 별도 확인이 필요합니다.

# 3. 경계·실폭에 붙인 결과 (전국)

중심선을 공간조인해 등급·하천명·하천코드를 붙였습니다. 두 자료는 **같은 국가기본도에서 같은
측량으로 나온 짝**이라(둘 다 2024-04-08 갱신) 형상이 정확히 대응합니다.

| 자료 | 총 폴리곤 | 소하천 | 지방하천 | 국가하천 | 등급미확인 |
|---|---:|---:|---:|---:|---:|
| 하천경계 | 140,396 | 90,556 | 42,505 | 4,690 | **2,645 (1.9%)** |
| 실폭 | 28,181 | 21,341 | 3,344 | 205 | 3,291 (11.7%) |

실폭의 등급미확인이 상대적으로 높은 것은 실폭 폴리곤이 중심선이 지나지 않는 소규모 수면을
포함하기 때문입니다. **등급을 추정해 채우지 않고 `등급미확인`으로 남깁니다.**

# 4. 하천망도만으로 국가기본도를 대체하기 어려운 이유

## 4.1 자료의 성격이 다릅니다

| | 하천망도 | 국가기본도 경계·실폭 |
|---|---|---|
| 단위 | 하천 1건 = 폴리곤 1건 (3,856건) | 측량 구간 단위 (168,577건) |
| 성격 | 법정 하천구역 | 측량 현황 형상 |
| 담는 등급 | 국가·지방하천 | 국가·지방·소하천·기타·세류 |

지도에 하천의 실제 모습을 그리려면 측량 현황 형상이 필요하고, 하천을 목록으로 식별하려면
하천 단위 자료가 필요합니다. 두 자료는 대체재가 아니라 보완재입니다.

## 4.2 하천망도에는 소하천이 없습니다

하천망도는 국가하천 73 · 지방하천 3,783건으로 국가·지방하천만 담고 있습니다.
전국 소하천은 **22,465개소**입니다(행정안전부 NDMS 소하천 전체 목록 기준).

## 4.3 하천망도로 등급을 조인하면 틀립니다

하천망도로 경계·실폭에 등급을 붙여 보고, 중심선 판정과 대조했습니다.

| 지역 | 하천망도가 판정한 건 | 중심선 판정과 일치 | 정확도 |
|---|---:|---:|---:|
| 의왕 하천경계 | 187 | 127 | 68% |
| 구미 하천경계 | 721 | 563 | 78% |
| 남원 하천경계 | 1,095 | 824 | 75% |

**틀리는 방향이 특히 문제입니다.**

```
소하천 → 지방하천으로 상향     의왕 46건 · 구미 106건 · 남원 205건
소하천 → 국가하천으로 상향     구미 52건
지방하천 → 국가하천으로 상향   남원 66건
```

하천망도의 법정 하천구역 폴리곤이 넓어 **본류에 합류하는 소하천 구간까지 삼키기** 때문입니다.
그 결과 소하천을 국가·지방하천으로 표시하게 되는데, 재난 대응 화면에서 하천 등급은 관리주체와
대응 절차를 가르는 값이라 상향 오판은 그대로 두기 어렵습니다.

# 5. 권고 구성

세 자료를 대체가 아니라 역할로 나눠 쓰는 구성입니다.

| 자료 | 역할 | 비고 |
|---|---|---|
| 하천일람 · 하천망도 | 하천 **목록·식별** — 코드·이름·등급·제원 | 국가 73 · 지방 3,783 |
| 국가기본도 **중심선** | 목록과 형상을 잇는 **다리** — 속성만 사용 | 형상은 반입하지 않음 |
| 국가기본도 **경계·실폭** | 지도 **표출 형상** | 등급·이름은 중심선에서 부착 |
| 소하천구역(연속주제도) | 소하천 **표출 형상 + 이름** | 전국 116,758 폴리곤 |
| NDMS 소하천 전체 목록 | 소하천 **목록**(모집단) | 22,465행 |

중심선은 형상을 반입할 필요가 없습니다. 322만 건을 선으로 겹쳐 그리면 시·군 화면에서 하천망이
오히려 묻히고, 하천의 모습은 경계·실폭·소하천구역이 면으로 이미 보여 줍니다.
**속성 조인 원천으로만 쓰면 충분합니다.**

# 6. 소하천 연결성

"별도로 확인 중"이라고 하신 부분입니다. 중복 작업을 줄이시도록 저희 대조 결과를 함께 드립니다.

## 6.1 조인 키

```
COL_ADM_SE (5자리 시군구코드)  +  정규화 소하천명(공백만 제거)
```

소하천구역 SHP에는 **소하천명 전용 필드도, 소하천 코드도 없습니다.** 이름은 `ALIAS`(별칭)와
`REMARK`(비고) 자유기술에 섞여 옵니다. 전국 116,758 폴리곤 기준 분포입니다.

| 이름이 있는 칸 | 폴리곤 | 비율 |
|---|---:|---:|
| `REMARK`에만 | 72,819 | 62.4% |
| 둘 다 | 33,913 | 29.0% |
| `ALIAS`에만 | 4,776 | 4.1% |
| 없음 | 5,250 | 4.5% |

`ALIAS`는 `소하천예정지`(47,768건)·`소하천구역`(10,549건) 같은 일반 라벨이 대부분이라
**`ALIAS`만 보면 이름의 3분의 2를 놓칩니다.** 두 칸을 모두 보고, 붙어 오는 고시번호·행정구역명·
구분(`웅곡천_무을면`, `운수천(001-2)`, `큰터골천 예정지03`)을 떼어내면 95.5%에서 이름을 얻습니다.

## 6.2 NDMS 목록과의 대조 결과

| 상태 | 행 | 비율 |
|---|---:|---:|
| 보유 (시군구코드·명칭 일치) | 17,613 | 78.4% |
| 경계걸침 후보 | 28 | 0.1% |
| 미보유 | 4,782 | 21.3% |
| 코드미상 | 42 | 0.2% |

미보유 4,782행 중 1,340행은 **형상이 없는 것이 아니라 그 시군구가 소하천구역에 하천명을 넣지
않은 것**입니다(순천시 252개소 중 SHP 이름 0종, 용인시 149개소 중 6종 — 그 6종도 경안천·탄천 등
본류명입니다).

## 6.3 조인 키로 쓰면 안 되는 것

| 후보 | 이유 |
|---|---|
| `MNUM` | 고시 관리번호입니다. 33자리지만 고시 단위 고유값이 전국 1,176개뿐이라 하천 식별자가 아닙니다 |
| NDMS 좌표 | 22,465행 중 시점 4,488행(20%)·종점 72행(0.3%)뿐이고, 단일 좌표계로 설명되지 않습니다(시도별 최적 원점을 잡아도 중앙오차 30~290 km) |
| NDMS 주소 | 462행이 개편 전 지명(청원군→청주시 등)이고 오입력도 섞여 있습니다 |
| 시군구를 넘는 명칭 일치 | 전국 하천명 12,477종 중 2,595종이 여러 시군구에 같은 이름으로 존재합니다(절골천 66곳·큰골천 57곳). 코드가 다른 동명 형상까지의 거리는 중앙값 26.2 km로 대부분 동명이인입니다 |

# 7. 수치 재현 방법

이 문서의 수치는 모두 원자료 전수 집계입니다. 직접 확인하실 수 있도록 근거를 적어 둡니다.

| 수치 | 근거 |
|---|---|
| 국가기본도 3종 필드 | 각 SHP의 DBF 헤더 필드 서술자 |
| 중심선 등급별 이름·코드 보유율 | `TN_RIVER_CTLN.dbf` 전수 3,224,769행 집계 |
| 코드 대조 99.1% / 98.8% | 중심선 `RIVER_NO` × 하천망도 `RIVCD_2` 집합 연산 |
| 전국 등급 분포 | 중심선 공간조인 산출물 집계 |
| 하천망도 조인 정확도 68~78% | 하천망도 조인 결과와 중심선 판정의 교차표(의왕·구미·남원) |
| 소하천 대조 78.4% | NDMS 소하천 전체 목록 22,465행 × 소하천구역 전국 116,758 폴리곤 |

문의 주시면 대조표 원본(시군구별 CSV)과 산출 스크립트를 함께 전달드리겠습니다.
