# v0.4 다중 페이지 접근성 점검표

## 공통
- [ ] 본문 바로가기 링크가 첫 번째 키보드 초점으로 제공된다.
- [ ] 각 페이지에 고유한 title과 하나의 h1이 있다.
- [ ] 주요 메뉴는 nav landmark이며 현재 링크에 aria-current가 있다.
- [ ] 브라우저 뒤로가기 후 현재 페이지와 초점이 일치한다.
- [ ] 200% 확대와 320 CSS px 너비에서 콘텐츠 손실이 없다.
- [ ] 모든 버튼과 링크의 클릭대상은 최소 24x24 CSS px, 내부 목표는 44px 이상이다.

## 재난 상황판
- [ ] 입력·Agent 탭과 판단 탭은 ArrowLeft/ArrowRight/Home/End를 지원한다.
- [ ] 지도 핵심 정보가 텍스트 목록으로 동등하게 제공된다.
- [ ] 레이어 토글은 aria-pressed 상태를 전달한다.
- [ ] 지도 연결상태와 오류가 화면낭독기에 전달된다.
- [ ] 우선 확인지역 카드는 마우스 클릭으로 지도 이동하고, 키보드는 지역명 버튼으로 같은 동작에 도달한다.
- [ ] 카드 상세보기 모달은 role="dialog"·aria-modal, 열 때 초점 이동, Esc·닫기·배경 클릭 닫기, 초점 가둠, 닫은 뒤 트리거 초점 복귀를 만족한다.

## 피해·변화 근거
- [ ] 모든 위성영상에 의미 있는 대체텍스트가 있다.
- [ ] 스와이프 외 좌우 비교 대체수단이 있다.
- [ ] range 입력은 보이는 label과 현재 값을 제공한다.
- [ ] 영상 메타데이터 표에 caption과 행·열 header가 있다.
- [ ] Seed와 비공식 상태를 색상 외 텍스트로 표시한다.

## 보고서 초안
- [ ] 모든 textarea에 보이는 label이 있다.
- [ ] 저장·다운로드 상태가 live region으로 전달된다.
- [ ] 보고서 미리보기를 키보드로 읽고 복사할 수 있다.
- [ ] 현재 피해 미확인 상태가 과거 Seed 피해와 혼합되지 않는다.
