타입 스케일 재정의 — 디자인 시스템 정렬

유동 clamp를 걷어내고 UNE 타입 토큰(11 / 12 / 14 / 16 / 20 / 24)에 고정한다. 자간 −3%, 굵기 400·500·700만 사용한다. 확대는 rem 유지로 1.4.4를 충족하며, 배율은 ≥2400px에서 한 번만 올린다.

루트 배율

≥1600px · ≥2000px 배율을 제거하고 100%로 되돌린다. ≥2400px만 106.25%(=17px)로 한 단계 올려 상황실 대형 모니터 원거리 판독을 지킨다. 1366px과 1920px의 렌더 크기가 같아져 밀도가 유지된다.

:root { font-size: 100% }
@media (min-width:2400px){ :root{ font-size:106.25% } }

토큰 교체값

--fs-xs:.6875rem; /* 11 / 17 */
--fs-sm:.75rem;   /* 12 / 18 */
--fs-md:.875rem;  /* 14 / 20 */
--fs-lg:1rem;     /* 16 / 24 */
--fs-title:1.25rem; /* 20 / 32 · 신규 h2 */
--fs-xl:1.5rem;   /* 24 / 36 */
Tweaks의 타입 스케일을 “현재(잠정값)”로 바꾸면 이 화면 전체가 기존 크기로 되돌아가 비교할 수 있다.

블루 크롬 — 신규 시맨틱 토큰 제안

시스템에 파랑 틴트 면·선 시맨틱 토큰이 없어 현재는 브랜드 프리미티브를 직접 참조한다. 아래 4개를 시맨틱으로 승격하면 인계문서 B-2 표에 흡수되고 하드코딩 색(F-13)도 함께 정리된다. 상태색(경고·오류·성공)은 파랑으로 바꾸지 않는다.

--surface-panel-blue:  var(--color-light-blue-25);  /* 보조 면·푸터바·요약칩 */
--border-panel-blue:   var(--color-light-blue-75);  /* 패널 테두리 */
--border-inner-blue:   var(--color-light-blue-50);  /* 내부 구분선 */
/* 강조선 var(--color-light-blue-200) · 지도 캔버스 var(--color-light-blue-50) */

F-14

sticky offset을 헤더 높이에서 파생시킨다

헤더 높이를 상수로 세 번 적어 어긋난 것이 원인이다. 헤더 높이를 토큰으로 노출하고 sticky는 계산식으로만 쓴다. 확대 브레이크포인트의 160 / 172 / 184px 오버라이드는 전부 삭제한다 — rem 기반이므로 ≥2400px 배율에서 헤더가 53px로 자라면 offset도 자동으로 따라간다.

:root{
  --header-h: 3.125rem;            /* 50px = DS Header */
  --sticky-gap: .5rem;             /* 8px */
  --sticky-offset: calc(var(--header-h) + var(--sticky-gap));
  --subnav-offset: calc(var(--header-h) + .25rem);
}
/* 삭제: @media(min-width:1600/2000/2400px){ --sticky-offset:160/172/184px } */
@media (max-width:900px){ :root{ --header-h:0px } } /* 헤더 static */
뷰포트 현재 offset 제안 offset 1366 · 1920px (헤더 50px) 78px 58px 1600 – 2399px 160 · 172px 58px ≥2400px (헤더 53px) 184px 61.5px
폴백: 헤더가 줄바꿈되는 폭(≤900px)에서는 헤더가 static이므로 --header-h를 0으로 덮는다. 런타임 실측이 필요하면 AppHeader가 ResizeObserver로 --header-h만 갱신한다(선택자·문구 변경 없음). --report-preview-h = calc(100vh − var(--header-h) − 5.5rem) — F-8의 상수 245px도 같은 방식으로 파생시킨다.
F-15

피해 카드의 열은 데이터가 결정한다

고정 3열(1.7fr 1fr 1fr)을 버리고 이력 유무에 따라 열 수를 바꾼다. “미확보” 표기는 D-2 요건이므로 지우지 않고, 빈 열이 아니라 카드 하단 데이터 상태 줄로 옮긴다. 클래스명은 유지하고 `data-history` 속성만 추가한다.

.damage-columns[data-history="both"]     { grid-template-columns:minmax(0,1.7fr) minmax(0,1fr) minmax(0,1fr) }
.damage-columns[data-history="response"],
.damage-columns[data-history="recovery"] { grid-template-columns:minmax(0,1.4fr) minmax(0,1fr) }
.damage-columns[data-history="none"]     { grid-template-columns:minmax(0,1fr) }   /* 금액 카드가 폭을 흡수 */
.damage-history-empty                    { /* 문구 유지 · 카드 하단 상태 줄로 이동 */ }
both — 3열
response — 2열
none — 1열 + 상태 줄
F-16

2560px 초과 — 지도 밀도 2단계와 패널 상한 해제

넓어지는 폭이 전부 지도로 가는 지금 구조에서는 3840px에서 지도만 2,950px로 늘고 정보밀도는 그대로다. 지도에 유효 상한을 주고, 남는 폭은 좌우 패널과 지도 오버레이 밀도에 배분한다.

폭 배분 (≥2561px, 밀도 tier B)

@media (min-width:2561px){
  --map-max: 2400px;             /* 지도 유효 상한 */
  --left-panel-w:  clamp(340px, 15vw, 460px);
  --right-panel-w: clamp(400px, 17vw, 560px);
  --overlay-inset: 20px;         /* 12 → 20 */
  --map-poi-size: 28px;          /* 24 → 28, 아이콘 램프 */
  --map-label-size: .8125rem;    /* 13 / 21 */
}
.dashboard-grid{ grid-template-columns:
  var(--left-panel-w) 26px minmax(420px,min(1fr,var(--map-max))) var(--right-panel-w) }
지도가 상한에 닿은 뒤 남는 폭은 우측 패널이 먼저 흡수하고, 그 다음 좌측이다. 우측 패널이 520px를 넘으면 우선 확인지역 카드가 2열(auto-fit minmax(320px,1fr))로 전환된다.

지도 오버레이 밀도 지침

POI · 라벨 아이콘 24→28px, 라벨 12→13px, 라벨 최소 간격 40px. 라벨 충돌 시 우선순위는 위험지구 > 하천 > 관측소.
클러스터 해제 임계 zoom을 +1 올린다(넓은 화면에서 개별 POI가 더 이른 배율에서 풀린다).
오버레이 배치 여백 20px. 레이어 칩은 한 줄 유지(줄바꿈 금지), 10개 초과분은 “더보기” 메뉴로 접는다. 팝업은 오버레이가 없는 우측에 배치해 연결상태·레이어 칩을 덮지 않는다(F-5).
타이포 본문은 ≥2400px 배율(106.25%)만 적용 — 밀도 tier B는 지도 안 요소에만 적용하고 패널 본문은 14px 기준을 유지한다.
