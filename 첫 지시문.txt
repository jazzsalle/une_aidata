이 저장소는 재난안전 AI데이터 활용 시범서비스의 공식 개발 기준선이다.

구현 정본:
1. 재난안전_AI데이터_시범서비스_글로드코드_개발인계문서_v1.0.md
2. 재난안전_AI데이터_활용_시범서비스_통합설계서_v1.8.1.docx
3. contracts/openapi/*.yaml
4. contracts/schemas/*.schema.json
5. server/contracts.ts
6. apps/web/src/types/contracts.ts
7. data/seed/*.json

현재 기준선:
- Design v1.8.1
- Source v1.5.1
- Mock/Seed 기본 운영
- Vercel Functions 31개 Route
- OpenAPI 31개 Operation
- JSON Schema 18종, 검증 객체 260개
- Runtime Regression 및 Provider Conformance PASS

작업 원칙:
- 기존 OpenAPI, JSON Schema, Seed ID 및 Provider 계약을 임의로 변경하지 않는다.
- 피해예측, 공식 위험도, 자동 조치결정으로 표현하지 않는다.
- Mock, Seed, Synthetic 자료는 실제 관측 또는 공식자료로 표시하지 않는다.
- 실제 T3Q 및 공공 API는 즉시 DEFAULT로 전환하지 않는다.
- 기존 시험을 통과한 상태를 유지하면서 작은 단위로 개발한다.
- 계약 변경이 필요하면 먼저 영향범위와 변경안을 보고하고 승인 전에는 수정하지 않는다.

먼저 다음 작업만 수행하라.
1. 저장소 구조와 인계문서를 분석한다.
2. package.json과 의존성을 점검한다.
3. npm install 가능 여부를 확인한다.
4. React Type Check와 Production Build를 수행한다.
5. 실패 원인을 수정하되 API·Schema·Seed 계약은 변경하지 않는다.
6. 수행 결과, 변경 파일, 잔여 오류를 보고한다.

아직 외부 Provider 연결이나 대규모 UI 개편은 시작하지 않는다.
